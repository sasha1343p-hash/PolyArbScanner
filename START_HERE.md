# 🔥 БЫСТРЫЙ СТАРТ - PolyArb Scanner

## ⚡ Самый простой способ (Windows)

**Просто дважды кликните на файл:**

```
start_app.bat
```

Это автоматически:
- ✅ Соберёт веб-дашборд (если нужно)
- ✅ Запустит веб-сервер на http://localhost:3000
- ✅ Запустит ML API на http://localhost:8000 (если есть venv)

---

## 🛠 Если `start_app.bat` не работает

### Шаг 1: Откройте терминал в корне проекта

**Windows:**
- Откройте папку проекта в Проводнике
- В адресной строке введите `cmd` и нажмите Enter

**Или:**
- Нажмите `Win + R`
- Введите `cmd`
- Перейдите в папку проекта: `cd путь\к\проекту`

### Шаг 2: Соберите проект

```bash
npm run build
```

Должно появиться:
```
✓ built in X.XXs
```

### Шаг 3: Запустите веб-сервер

```bash
npx serve dist
```

Должно появиться:
```
Serving!
Local: http://localhost:3000
```

### Шаг 4: Откройте в браузере

Перейдите по адресу: **http://localhost:3000**

---

## 🐛 Если видите ошибку 404

### Причина 1: Папка `dist/` не создана

**Решение:**
```bash
npm run build
```

### Причина 2: Веб-сервер не запущен

**Решение:**
```bash
npx serve dist
```

### Причина 3: Неправильный URL

**Правильный URL:** `http://localhost:3000`

**НЕ:** `http://localhost:3000/index.html`

## 🎯 Проверка работы

### 1. Веб-дашборд работает?

Откройте: **http://localhost:3000**

Должна отобразиться панель с:
- 📊 Карточками метрик
- 📈 Таблицей возможностей
- 📉 Графиком истории edge
- 🔍 Фильтрами

### 2. ML API работает? (опционально)

Откройте: **http://localhost:8000/api/health**

Должен вернуться JSON:
```json
{
  "status": "ok",
  "model_loaded": true,
  "database_exists": true
}
```

## 🆘 Если ничего не работает

### Проверьте Node.js
```bash
node --version
npm --version
```

Должно вывести версии (например, `v20.11.0` и `10.2.4`)

### Переустановите зависимости
```bash
npm install
```

### Проверьте порт 3000
```bash
netstat -ano | findstr :3000
```

Если порт занят, используйте другой:
```bash
npx serve dist -p 3001
```
