# 🚀 Применение обновлений ML Oracle


## 🔍 Проверка новых фич

### Посмотреть извлеченные фичи

```python
from ml_oracle.feature_extractor import FeatureExtractor, MarketMetadata
import pandas as pd

# Загрузить данные
metadata = MarketMetadata(
    id='test-001',
    question='Will Bitcoin be above $100,000 by March 2026?',
    end_date=pd.Timestamp('2026-03-01')
)

price_df = pd.DataFrame({
    'timestamp': pd.date_range('2026-01-01', periods=100, freq='h'),
    'yes_price': [0.5 + i*0.001 for i in range(100)],
    'volume': [1000] * 100,
    'liquidity': [5000] * 100
})

# Извлечь фичи
extractor = FeatureExtractor()
features = extractor.extract_features('test-001', price_df, metadata)

# Посмотреть новые фичи
print("Days to expiry:", features['days_to_expiry'])
print("Market type crypto:", features['market_type_crypto'])
print("Volatility:", features['volatility'])
print("Trend:", features['trend'])
```

**Ожидаемый вывод:**
```
Days to expiry: 45
Market type crypto: 1.0
Volatility: 0.001
Trend: 0.001
```

## 🐛 Решение проблем

### Проблема: "Модель не обучена"

**Решение:**
```bash
run.bat train
```

---

### Проблема: "AUC-ROC < 0.65"

**Причины:**
1. Недостаточно данных (< 200 рынков)
2. Сильный дисбаланс классов
3. Слишком шумные данные

**Решения:**
1. Добавить больше данных в БД
2. Проверить баланс: `run.bat check_class_balance.py`
3. Увеличить `scale_pos_weight` в конфиге

---

### Проблема: "Тесты не проходят"

**Решение:**
```bash
# Переобучить модель
run.bat train

# Запустить тесты заново
pytest ../tests/ -v
```

---

### Проблема: "Калибровка не улучшает модель"

**Причины:**
1. Модель уже хорошо калибрована
2. Недостаточно данных для калибровки
3. Метод sigmoid не подходит

**Решения:**
1. Использовать оригинальную модель без калибровки
2. Попробовать метод isotonic: `calibrator.calibrate(method='isotonic')`
3. Добавить больше данных для калибровки
