# 🚀 Быстрая установка (3 минуты)

## ⚡ Один клик — всё готово!

### Windows

Просто дважды кликните на файл:

```
📁 polymarket_ml
└── 📄 setup.bat          ← Двойной клик!
```

**Что произойдёт:**
1. ✅ Проверит Python
2. ✅ Создаст виртуальное окружение
3. ✅ Установит все зависимости
4. ✅ Создаст тестовую базу данных
5. ✅ Обучит ML модель
6. ✅ Сделает тестовое предсказание

---

### Linux / macOS

Откройте терминал в папке `polymarket_ml` и выполните:

```bash
python3 setup_crossplatform.py
```

---

## 🎯 После установки

### Вариант 1: Быстрый запуск всего

**Windows:**
```cmd
start_all.bat
```

**Linux / macOS:**
```bash
chmod +x start_all.sh
./start_all.sh
```

Откроет:
- 📊 Веб-дашборд: http://localhost:3000
- 🔮 ML API: http://localhost:8000

---

### Вариант 2: CLI команды

```bash
# Предсказание для рынка
python ml_oracle.py predict market-001

# Проверка дрейфа
python ml_oracle.py drift-check

# Важность признаков
```

## 🐛 Если что-то пошло не так

### Ошибка: "Python не найден"

**Решение:** Установите Python 3.10+ с [python.org](https://python.org)

⚠️ **ВАЖНО:** При установке отметьте **"Add Python to PATH"**

---

### Ошибка: "cannot be loaded because running scripts is disabled"

**Решение:** Откройте PowerShell от имени администратора и выполните:

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

---

### Ошибка: "Не удалось установить зависимости"

**Решение:** Удалите папку `venv` и запустите установку заново:

```cmd
rmdir /s venv
setup.bat
```
