# 🚀 Быстрый старт (5 минут)

## 1. Установка (1 минута)

```bash
# Клонируем или скачиваем проект
cd polymarket_ml

# Создаём виртуальное окружение
python -m venv venv

# Активируем (Windows)
venv\Scripts\activate

# Устанавливаем зависимости
pip install -r requirements.txt
```

## 2. Проверка данных (30 секунд)

Убедитесь, что у вас есть файл `polymarket_history.db`:

```bash
# Проверка наличия БД
ls polymarket_history.db

# Проверка количества данных
sqlite3 polymarket_history.db "SELECT COUNT(*) FROM market_metadata WHERE resolution IS NOT NULL;"
```

Должно быть **минимум 100 рынков** с `resolution IS NOT NULL`.

## 3. Обучение модели (2-3 минуты)

```bash
# Запуск обучения
python ml_oracle.py train
```

**Ожидаемый вывод:**

## 4. Первое предсказание (30 секунд)

```bash
# Получаем ID любого рынка из БД
sqlite3 polymarket_history.db "SELECT id FROM market_metadata LIMIT 1;"

# Предсказываем (замените market-id на реальный ID)
python ml_oracle.py predict <market-id>
```

**Пример вывода:**

## ✅ Готово!

Теперь вы можете:
- Обучать модель: `python ml_oracle.py train`
- Делать предсказания: `python ml_oracle.py predict <market-id>`
- Проверять дрейф: `python ml_oracle.py drift-check`
- Смотреть важность признаков: `python ml_oracle.py feature-importance`

## 🐛 Проблемы?

### "Недостаточно данных для обучения"
- Нужно минимум 100 рынков с `resolution IS NOT NULL`
- Проверьте: `sqlite3 polymarket_history.db "SELECT COUNT(*) FROM market_metadata WHERE resolution IS NOT NULL;"`

### "AUC-ROC ниже порога 0.65"
- Модель работает, но качество можно улучшить
- Попробуйте увеличить количество данных
- Настройте гиперпараметры в `configs/oracle_config.yaml`

### "Модель не загружена"
- Сначала выполните обучение: `python ml_oracle.py train`
- Проверьте наличие файла: `artifacts/ml_oracle_bundle.pkl`

### Windows: "python не найден"
- Установите Python 3.10+ с [python.org](https://python.org)
- Добавьте Python в PATH при установке
