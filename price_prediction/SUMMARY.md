# 🎯 Price Prediction System - Резюме

## ✅ Что создано

### Основные файлы (5 модулей)

1. **`src/target_generator.py`** ✅
   - Генерация целевой переменной
   - Определяет: вырастет ли цена на X% за Y часов
   - Параметры: threshold, horizon, min_data_points

2. **`src/feature_extractor.py`** ✅
   - Извлечение 50+ признаков из временных рядов
   - Momentum, Volatility, Trend, SMA, RSI, Volume, Distance, Time
   - Окна: 1h, 6h, 12h, 24h, 48h, 168h

3. **`src/prepare_dataset.py`** ✅
   - Объединение фич и targets
   - Очистка данных
   - Статистика датасета

4. **`src/model.py`** ✅
   - Обучение XGBoost модели
   - TimeSeriesSplit кросс-валидация
   - Балансировка классов (scale_pos_weight)
   - Feature importance

5. **`src/backtester.py`** ✅
   - Бэктестинг стратегии на истории
   - Расчет P&L, win rate, max drawdown, Sharpe ratio
   - Симуляция торговли

### Скрипты запуска (3 файла)

1. **`run_pipeline.py`** ✅
   - Главный скрипт запуска всего пайплайна
   - Поддержка шагов 1-5
   - Параметры: --step, --skip-backtest, --threshold, --horizon

2. **`run_target_generation.py`** ✅
   - Скрипт генерации targets
   - Параметры: --threshold, --horizon, --min-points, --output

3. **`run_all.bat`** ✅
   - BAT-файл для Windows
   - Автоматическая активация venv
   - Проверка зависимостей

### Конфигурация и зависимости (2 файла)

   - Параметры генерации targets

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
cd price_prediction
pip install -r requirements.txt
```

### 2. Запуск пайплайна

```bash
python run_pipeline.py
```

Или на Windows:
```cmd
run_all.bat
```

## 🔧 Настройка параметров

### Консервативная стратегия

```bash
python run_pipeline.py --threshold 0.10 --horizon 48
```

- Порог роста: 10%
- Горизонт: 48 часов
- Меньше сделок, выше качество

### Агрессивная стратегия

```bash
python run_pipeline.py --threshold 0.03 --horizon 12
```

- Порог роста: 3%
- Горизонт: 12 часов
- Больше сделок, ниже качество

### Стандартная стратегия

```bash
python run_pipeline.py --threshold 0.05 --horizon 24
```

- Порог роста: 5%
- Горизонт: 24 часа
- Баланс между количеством и качеством
